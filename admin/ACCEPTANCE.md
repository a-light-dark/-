## 2. 圈主手动验收（真机/体验版，约 10 分钟）

- [ ] 管理台 → 仪表盘：数字和实际库对上（帖子数、举报数）
- [ ] 公告管理 → 发一条「测试公告」→ 退出到首页 → 看到绿色公告卡 → 点开是全文 → 回管理台删掉
- [ ] 运营配置 → banner 文案改成「欢迎新同学」→ 首页紫色 banner 标题变了 → 改回清空
- [ ] 用户管理 → 搜一个昵称 → 封禁（填原因）→ 列表显示已封禁 → 解封
- [ ] 帖子管理 → 随便删一条测试帖 → 回收站里能「恢复」
- [ ] 敏感词库 → 加「测试词」→ 自己发一条带「测试词」的帖 → 被拒 → 删词 → 能发
- [ ] 数据备份 → 开始备份 → 列表出现 → 复制链接去浏览器能下载 JSON → 删除
- [ ] 审计日志：做完上面这些，运营配置页底部审计列表变长了

## 3. 双人验收（需要朋友配合，约 5 分钟）

- [ ] 你封禁朋友的号 → 朋友发帖/评论/抢单/点赞都提示「你的账号已被圈主限制」→ 你解封 → 朋友恢复正常
- [ ] 朋友发一条违规内容（如「代开发票」）→ 被微信内容安全拒 → 你在仪表盘看到 0 新增（没写库）
- [ ] 朋友举报一条帖子 → 你「举报处理」里能看到 → 忽略或删帖 → 朋友侧帖子消失
